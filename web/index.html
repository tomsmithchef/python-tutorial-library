Introduction to Python Programming Language

This chapter is written for someone who may have never programmed before. The goal is not only to memorize syntax, but to understand what Python is asking you to think about: values, names, instructions, structure, and small repeatable habits that make code easier to read.

1. Python and Programs

Python is a general-purpose programming language. General-purpose means the language is not designed for only one narrow job. The same language can be used to automate boring tasks, analyze data, build a web application, work with files, create a small desktop tool, experiment with artificial intelligence, or write scripts that help manage a computer system. For a beginner, this flexibility matters because the early ideas you learn are not throwaway ideas. Variables, strings, lists, dictionaries, input, output, and operators appear almost everywhere Python is used.

Python is often described as readable. That does not mean every Python program is automatically easy, but it does mean the language tries to keep common actions close to plain English. A line such as print("Hello") is understandable even before you know every technical term around it. The word print names the action, the parentheses hold the information being sent into the action, and the quoted text is the message being displayed.

Beginner mental model

A Python program is a recipe for the computer. Each line gives an instruction. Python reads many simple scripts from top to bottom, carrying values forward as it goes. If a value is placed into a variable, later lines can use that variable instead of typing the value again.

Python is high level, dynamically typed, and usually platform independent for beginner scripts. High level means Python hides many machine-level details so you can focus on the problem you are trying to solve. Dynamically typed means a variable does not need a declared type before you assign a value to it. If you write name = "Amina", Python understands that the value is text because the value itself is text. Platform independent means the same basic script can usually run on Windows, macOS, or Linux as long as Python is installed.

2. Tools, Scripts, and Your First Output

Beginners often confuse Python the language with the program used to write Python. Python is the language and runtime. IDLE, the command-line shell, and PyCharm are tools that help you write or run Python code. An IDE, short for Integrated Development Environment, combines a code editor, project view, run button, terminal, and error display into one workspace. PyCharm is one IDE. You could also write Python in many other editors, but a course may choose one tool so everyone sees similar screens.

A Python file usually ends with .py. If you save a file as hello_world.py, you are telling yourself and your tools that the file contains Python code. The classic first program is short because it teaches several ideas at once: calling a function, passing a string into that function, and viewing output in the console.

hello_world.py
print("Hello, world!")

Try it in your IDE: create a file named hello_world.py, paste the example, and run it from PyCharm.

Expected output 
Hello, world!

The quotes are important because they tell Python that Hello, world! is literal text. The parentheses are also important because they complete the function call. If one quote or parenthesis is missing, Python will not guess what you meant. It will stop and show an error message. At the beginning, many errors are punctuation errors, not deep logic problems.

3. Coding Standards, PEP 8, Comments, and Docstrings

Code is written once but read many times. You may read your own code again tomorrow, your instructor may read it while grading, and a future teammate may read it while fixing a bug. Coding standards exist so code looks predictable. In Python, the best-known style guide is PEP 8, which gives recommendations for names, whitespace, line length, comments, and other habits.

PEP 8 means Python Enhancement Proposal 8. A Python Enhancement Proposal is a written design document used by the Python community. PEP 8 is not a separate programming language and it is not required for Python to run your code. Instead, it is the common style agreement Python programmers use so code from different people still feels familiar. When a class, workplace, or team says “write Python style,” they usually mean “follow PEP 8 unless the project has a specific reason to do something else.”

PEP 8 style habits

Topic Beginner rule Why it matters
One statement per line Avoid squeezing several actions onto one line. It makes code easier to scan and easier to debug.
Spaces around operators Prefer total = price * quantity. The calculation is visually separated from the assignment.
No extra space before calls Write print("Hi"), not print ("Hi"). The function name and call parentheses belong together.
No extra space inside brackets Write cars[1], not cars[ 1 ]. Indexing stays compact and readable.
Block comments Start each line with # and align it with the code it describes. The reader can tell which code the explanation belongs to.
Inline comments Place at least two spaces before #, then one space after it. The code and comment stay visually distinct.

Whitespace matters in two ways. First, whitespace makes code comfortable to read. A line like total = price * quantity is easier to scan than total=price*quantity. Second, indentation has meaning in Python. In many languages, braces mark a block of code. In Python, indentation marks the block. When you later write an if statement or a loop, the indented lines belong to that structure.

Readable style
# Calculate the total price before tax.
quantity = 3
price = 19.99
total = quantity * price

print(total)

Try it in your IDE: run the example once, then change quantity and predict the new output before running again.

Comments begin with #. A good comment explains purpose, context, or a decision that is not obvious from the code itself. Comments should not simply translate every line into English. If a variable is named clearly, the code already says a lot. For example, quantity = 3 rarely needs a comment saying “set quantity to 3.” A better comment explains why that quantity matters.

A docstring is a documentation string. It uses triple quotes and usually appears at the top of a module, function, class, or method. In Lesson 1, you only need to recognize the idea. Later, when you write your own functions, docstrings become a clean way to explain what a function does before someone reads its internal code.

Lesson 1 also distinguishes one-line and multi-line docstrings. A one-line docstring opens and closes on the same line and briefly states the action, such as """Return the account balance.""". A multi-line docstring closes on its own line and gives more context. For scripts, a docstring can describe the script’s purpose and how to run it. For modules, it can summarize the functions, classes, or values the module provides.

Module docstring
"""Practice script for assigning the same value to two variables."""

first_greeting = second_greeting = "Good day"

# Display both assigned variables.
print(first_greeting)
print(second_greeting)

4. Keywords, Statements, Indentation, and Program Structure

Keywords are reserved words that Python uses for its own grammar. Words such as if, while, for, class, return, True, False, and None have special meaning. Because Python needs those words to understand your program, you cannot use them as ordinary variable names. You can explore the full list by running help("keywords") in Python.

Python is case sensitive. That means True and true are not the same thing. The capitalized True is a Boolean literal built into the language. The lowercase true is just a name Python does not know unless you define it yourself. The same rule applies to variable names: first_name, First_Name, and firstName are three different names.

A statement is an instruction Python can execute. Assignment is one kind of statement: score = 10. A print call is another kind: print(score). Some statements create blocks. A block is a group of lines that belong together. In the example below, the indented print line belongs to the if statement.

Indented block
is_ready = True

if is_ready:
    print("The block ran.")

print("The program is done.")

Try it in your IDE: remove the indentation before the first print() and notice how the meaning changes.

When a statement becomes long, Python allows continuation across lines. Parentheses, brackets, and braces are the clearest way to continue a line because Python can see that the expression has not finished yet. A backslash can also continue a line, but beginners should prefer parentheses when possible because they are easier to read and harder to break accidentally.

5. Variables, Constants, Naming, and Types

A variable is a name that refers to a value. Many beginner explanations describe a variable as a box, and that image is helpful at first. A slightly more accurate Python image is a label attached to an object. When you write first_name = "John", Python creates or uses the string object "John" and lets the name first_name refer to it.

Python does not require you to declare the variable type before assigning a value. You do not write string first_name. You simply write the assignment, and Python understands the type from the value. A value in quotes is a string. A whole number such as 5 is an integer. A number with a decimal point such as 5.0 is a float.

Variables and type()
first_name = "John"
age = 25
price = 150.75

print(first_name)
print(type(first_name))
print(type(age))
print(type(price))

Try it in your IDE: add one more variable of your own and print its type.

Good names make code easier to understand. A variable named x is legal, but it tells the reader almost nothing. A variable named total_price explains its role. If a name has multiple words, Python style usually uses lowercase words separated by underscores. Names should not start with a digit, should not contain special characters such as ! or @, and should not be a keyword.

Constants are values that are meant to stay the same while the program runs. Python does not prevent you from changing them, so programmers use uppercase names as a promise: DISCOUNT_RATE = 0.20. The uppercase name tells the reader that the value is part of the program’s setup and should be treated carefully.

Multiple assignment lets you assign several values in one statement. Same-value assignment lets several names point to the same value. These tools are convenient, but clarity still matters. Use them when they make the relationship obvious.

Multiple assignment
first_name, last_name = "John", "Bello"
city = campus = "Ottawa"

print(first_name, last_name)
print(city, campus)

6. Literals, Strings, Escape Sequences, and Formatting

A literal is a value written directly into the program. In score = 10, the number 10 is a numeric literal. In message = "Welcome", the quoted text is a string literal. Python includes numeric literals, Boolean literals, string literals, the special literal None, and collection literals such as lists, tuples, dictionaries, and sets.

Numeric literals can be integers, floats, or complex numbers. Integers are whole numbers. Floats hold decimal values. Complex numbers use j for the imaginary part. Python can also write integers using binary, octal, or hexadecimal notation, although beginners usually start with ordinary decimal numbers.

Numeric literals
binary_value = 0b1010
decimal_value = 200
float_value = 3.5e2
complex_value = 3.14j

print(binary_value)
print(decimal_value)
print(float_value)
print(complex_value.imag)

Strings are sequences of characters. They can be written with single quotes, double quotes, or triple quotes. Triple quotes are useful for text that spans more than one line. Escape sequences start with a backslash. For example, \n means newline and \t means tab. Escape characters are also used when you need to place a quote inside a string that uses the same quote style.

Strings and methods
sentence = "What a wonderful day"

print(sentence.capitalize())
print(sentence.find("day"))
print(sentence.replace("day", "evening"))
print(sentence.count("a"))

Try it in your IDE: change the sentence and check whether the index returned by find() changes.

String methods return useful transformed values. They do not change the original string because strings are immutable. If you want to keep a transformed value, assign it to a variable. Formatting is another important string skill. The format() method can insert values into a sentence, add commas to large numbers, and display currency-like values with two decimal places.

String method reference

You do not need to memorize every string method at once, but you should know what kind of job each one performs. Methods are called with dot notation, such as sentence.upper().

7. Lists, Tuples, Dictionaries, and Sets

Collections let one variable hold multiple values. The four collection types introduced in Lesson 1 are lists, tuples, dictionaries, and sets. They are not interchangeable. Each one answers a different beginner question: Do I need order? Do I need to change the collection? Do I need labels? Do I need uniqueness?

Indexing, slicing, and mutability by data type

This is one of the biggest Lesson 1 ideas to keep straight. Some data types are sequences and support numeric indexes. Some are collections but do not use numeric positions. Some can be changed after they are created, and some cannot.

Type Ordered? Indexing / slicing? Changeable? Beginner note
str Yes Yes: school[4], school[1:6] No Strings are sequences of characters, but you cannot replace one character in place.
list Yes Yes: cars[0], cars[2:] Yes Lists are the flexible beginner collection for ordered data.

dict Insertion ordered in modern Python Key lookup, not numeric indexing: car["brand"] Yes Dictionaries use meaningful keys instead of positions.

Lists

A list is an ordered and changeable collection. Ordered means every item has a position. Changeable means you can add, remove, or replace items after the list is created. Python indexes begin at zero, so the first item is at index 0, the second item is at index 1, and so on. Negative indexes count from the end, making cars[-1] a useful way to refer to the last item.

List operations
cars = ["Honda", "Toyota", "Mercedes", "Ferrari", "Nissan", "Hyundai"]

print(cars[2])
cars[-1] = "Kia"
cars.insert(2, "Chevrolet")
cars.reverse()
print(cars)

Try it in your IDE: print the list after every list method so you can see each change happen.

Lists can be looped through directly when you need each item, or by index when the position matters. A direct loop is easier to read. An index loop is useful when the assignment specifically asks you to use indexes or when you need both the position and the value.

Tuples

A tuple is ordered like a list, but immutable. Once created, its individual items cannot be changed. This makes tuples useful when the data should be protected from accidental edits. Tuples can be indexed, sliced, unpacked into variables, joined with another tuple, counted, and searched with index().

Negative tuple indexing starts from the end, so fruit_tuple[-1] means the last item and fruit_tuple[-2] means the second-last item. Tuple ranges work like list ranges: tuple_name[2:6] includes index 2 and stops before index 6. If a tuple truly needs to be changed, the usual workaround is to convert it to a list, change the list, and convert it back to a tuple.

Dictionaries

A dictionary stores key-value pairs. Instead of remembering that a value is at position 0 or 1, you give it a label. A car dictionary might use the keys "brand", "model", and "year". The values could be "Ford", "Mustang", and 2022. Dictionaries are excellent for representing real-world objects with named properties.

Dictionary operations
car = {

    "model": "Mustang",
    "year": 2022,

print(car["brand"])
print(car.keys())
print(car.items())

Sets

A set is an unordered collection of unique items. If the same value is added more than once, the set keeps only one copy. Sets are especially useful for comparing groups. You can find what two groups have in common with intersection, combine groups with union, find what one group has that another does not with difference, and find values that belong to one group but not both with symmetric difference.

Set operations

print(basketball.union(baseball))
print(baseball.difference(basketball))

8. Type Conversion, Input, Output, and Imports

Type conversion means changing a value from one type to another. Python sometimes performs safe conversions automatically. For example, adding an integer and a float produces a float because the decimal part must be preserved. This is implicit conversion. Explicit conversion happens when you call a function such as int(), float(), str(), list(), tuple(), or set() yourself.

Conversion is powerful but should be done thoughtfully. Converting the string "456" to an integer gives the number 456, which can be used in arithmetic. Converting -10.6 to an integer gives -10, which loses the decimal portion. That is why the lesson notes warn that type casting can lose data.

Conversion
num_int = 123
num_float = 1.23
print(num_int + num_float)

num_text = "456"
num_value = int(num_text)
print(num_int + num_value)

User input is collected with input(). The important beginner rule is that input() always returns a string. If the user types 7, Python receives "7", not the integer 7. To add numbers entered by a user, convert the input first.

Input pattern
first_number = int(input("Enter the first number: "))
second_number = int(input("Enter the second number: "))
total = first_number + second_number

print("The sum of {0} and {1} is {2}".format(first_number, second_number, total))

Imports let a program use code from another module. A module is a Python file containing definitions and statements. Python includes many useful standard modules. The math module contains mathematical constants and functions, including pi. You can import the module as a whole with import math, or import a specific name with from math import pi.

9. Operators

Operators perform actions with values. Arithmetic operators handle math. Comparison operators ask questions and return True or False. Assignment operators update variables. Logical operators combine conditions. Identity and membership operators answer more specialized questions.

Arithmetic operators include addition, subtraction, multiplication, division, modulus, floor division, and exponentiation. Division with / returns a float. Floor division with // returns the whole-number floor of the result. Modulus with % returns the remainder, which is useful for patterns such as checking whether a number is even.

Arithmetic and comparison
x = 15
y = 4

print("x + y =", x + y)
print("x - y =", x - y)
print("x * y =", x * y)
print("x > y is", x > y)
print("x < y is", x < y)

The assignment operator = stores a value in a variable. The comparison operator == checks whether two values are equal. This difference is one of the most important beginner details in programming. Writing total = 12 assigns the value. Writing total == 12 asks a question whose answer is True or False.

Logical operators are and, or, and not. The operator and requires both sides to be true. The operator or requires at least one side to be true. The operator not reverses a Boolean value. Membership operators such as in and not in check whether a value appears in a collection or string.

1. Flow Control

Flow control is the part of programming that decides which instructions run, which instructions are skipped, and which instructions repeat. Without flow control, a program runs straight from top to bottom every time. That is useful for very small scripts, but real programs usually need to respond to changing information. A loan program might approve one customer and reject another. A grade program might print a different message for an A, B, C, or failing mark. A game might decide that Player 1 wins, Player 2 wins, or the round is a draw.

A decision-making statement evaluates a condition. A condition is an expression that becomes either True or False. If the condition is true, Python runs the block connected to that condition. If the condition is false, Python skips that block and may run a different block instead. Conditions usually use comparison operators such as >, <, ==, >=, and <=, often combined with logical operators such as and and or.

Decision statement reference

Statement Purpose Beginner use case
if Run a block only when one condition is true. Print a message only if a number is positive.
if...else Choose between two possible paths. Approve or reject a loan when there are two outcomes.
if...elif...else Check several possible conditions in order. Classify a number as positive, zero, or negative.
Nested if Place one decision inside another decision. Check a second requirement only after the first requirement passes.

Beginner mental model

Think of flow control as a fork in the road. The program reaches a question, checks the answer, and follows the matching path. Indentation shows exactly which lines belong to each path.

2. If, Else, and Elif

The simplest decision uses if. An if statement has a condition followed by a colon. The indented block underneath runs only when the condition is true. If the condition is false, Python skips the indented block and continues after it.

Simple if statement
num = 30

if num > 0:
    print(num, "is a positive number.")

print("Outside the if statement.")

Try it in your IDE: change num to a negative value and observe which line no longer runs.

An if...else statement gives Python two paths. If the condition is true, the if block runs. If the condition is false, the else block runs. This is useful when exactly one of two outcomes should happen.

If and else
num = 10

if num >= 0:
    print("Positive or zero")
else:
    print("Negative number")

Condition operators

Conditions are built from comparisons and logical combinations. These expressions do not print by themselves; they evaluate to True or False, and the decision statement uses that result.

When there are more than two possible outcomes, use elif, short for "else if." Python checks the first condition, then each elif condition in order, and finally the optional else block if nothing else matched. The order matters. Put the most specific checks where they make the most sense, and make sure the final else represents the leftover case.

3. Nested Decisions

A nested if statement is an if statement placed inside another if statement. Nesting is sometimes useful because one question only matters after another question has already been answered. For example, a number can only be checked for being exactly zero after the program has already decided it is not negative.

Nested if statement
num = float(input("Enter a number: "))

if num >= 0:
    if num == 0:
        print("Zero")
    else:
        print("Positive number")
else:
    print("Negative number")

The risk with nesting is readability. Every indentation level asks the reader to keep more context in their head. Nested decisions are not wrong, but beginners should use them carefully. If a nested block becomes hard to explain out loud, the program may be easier to understand with elif, helper variables, or smaller functions in later lessons.

4. Loops

A loop repeats a statement or a group of statements. Loops are one of the main reasons programming is powerful: the computer can repeat a task hundreds or thousands of times without getting tired. Lesson 2 introduces while loops, for loops, and nested loops.

A while loop repeats while a condition remains true. Because the condition is checked before each repetition, the loop may run many times, one time, or not at all. A common beginner pattern is to create a counter before the loop, check the counter in the condition, and update the counter inside the loop. Forgetting the update is a classic way to create an infinite loop.

While loop counter
i = 1

while i <= 5:
    print(i)
    i = i + 1

A for loop is used to iterate over a sequence or iterable object. A sequence can be a list, tuple, string, or a range of numbers. The range() function is common when you need a series of integers. range(1, 6) produces the values 1 through 5, because the ending value is not included.

For loop with range
for i in range(1, 6):
    print(i)

A nested loop is a loop inside another loop. Nested loops are useful for tables, grids, and combinations, but they multiply the amount of work. If an outer loop runs 10 times and an inner loop runs 10 times, the inner body can run 100 times. That is powerful, but it should be intentional.

Loop reference

for for value in sequence: Visit every item in a list, tuple, string, range, or other iterable.
Nested loop A loop inside another loop. Build tables, grids, or compare combinations of items.

Understanding range()

range() creates a sequence of integers for looping. The stop value is not included, which is why range(1, 6) gives 1 through 5.

5. Break and Continue

Sometimes a loop should not run all the way to its natural end. The break statement exits the loop immediately. After break, Python continues with the first line after the loop. This is useful when the program has found what it was looking for or when continuing would be unnecessary.

Break
for val in "Hello":
    if val == "e":
        break
    print(val)

print("The end")

The continue statement skips the rest of the current iteration and moves to the next one. It does not end the whole loop. In the example below, the letter e is skipped, but the loop continues with the remaining letters.

Continue
for val in "Hello":
    if val == "e":
        continue
    print(val)

print("The end")

break vs continue

Statement Effect In "Hello" example
break Exit the whole loop immediately. The loop stops when it reaches "e".
continue Skip the rest of the current iteration and continue with the next item. The letter "e" is skipped, but later letters still run.

6. Command-Line Arguments

Command-line arguments are values typed after the script name when a program is run from a terminal. They let a script receive information without using input(). This matters when you want to run a program from PowerShell, Command Prompt, a scheduled task, another program, or an automated workflow.

For example, a script named add_numbers.py might be run as python add_numbers.py 4 4 4. The script name is the command being executed, and the values after it are arguments. Lesson 2 introduces three ways to work with those arguments: sys.argv, getopt, and argparse.

8. getopt

The getopt module helps parse command-line options. Options are arguments that usually begin with a dash, such as -h for help or -o Colors for an option named o with a value. Compared with plain sys.argv, getopt gives more structure, but it also requires more setup.

getopt pattern
import getopt
import sys

argv = sys.argv[1:]

try:
    opts, args = getopt.getopt(argv, "ho:v")
    print(opts)
    print(args)
except getopt.GetoptError:
    print("Something went wrong!")
    sys.exit(2)

In the option string "ho:v", the letters describe which short options are accepted. A colon after a letter means that option expects a value. This style is common in older command-line tools, but for many new Python programs, argparse is friendlier.

9. argparse

The argparse module is the preferred standard-library tool for many command-line programs. It can define positional arguments, optional arguments, help messages, descriptions, defaults, and type conversions. A positional argument is required because its position matters. An optional argument usually begins with a dash and can be omitted.

argparse pattern
import argparse

parser = argparse.ArgumentParser(description="Add two numbers.")
parser.add_argument("first_number", help="Enter the first number")
parser.add_argument("second_number", help="Enter the second number")

first_number = int(args.first_number)
second_number = int(args.second_number)

print("The sum of the two numbers is", first_number + second_number)

A major benefit of argparse is that it can generate help text. If the user runs a script with -h, argparse can explain what arguments the script expects. That makes command-line tools easier to use and easier to grade because the interface is documented by the program itself.

Python Functions

Lesson 3 is about turning repeated logic into named, reusable pieces. A function lets you give a task a name, describe what information it needs, run that task whenever needed, and optionally send a result back to the caller. Once you understand functions, your programs become easier to organize, test, explain, and expand.

1. Why Functions Matter

A function is a group of related statements that performs a specific task. That definition sounds simple, but it changes how you design programs. Without functions, a program often becomes one long sequence of instructions. At first that feels direct, but as the program grows, repeated code appears, small changes become harder to make, and it becomes difficult to tell where one idea ends and another begins.

Functions solve that problem by creating smaller modules of behavior. A program that calculates interest can have one function for collecting input, one function for calculating interest, and one main function that controls the order of events. A loan program can use a function to check whether a customer qualifies. A list-processing program can use a function to count only integer values. The function name becomes a readable label for the task.

Beginner mental model

Think of a function as a reusable mini-program inside your program. It does not run just because it exists. It runs when you call it.

What functions are responsible for

Purpose What it means for a beginner
Organization A function gives a name to a task, so the main program can read like a short sequence of meaningful actions.
Reuse If the same calculation or validation is needed more than once, a function lets you write it once and call it many times.
Testing Small functions are easier to test because you can give them inputs and check the returned result.
Maintenance When a rule changes, updating one function is safer than searching for repeated copies of the same logic.

2. Defining and Calling a Function

Python creates functions with the def keyword. The function definition starts with def, then the function name, then parentheses, then a colon. The indented block underneath is the function body. The body contains the statements that run when the function is called.

Function definition and call
def greet(name):
    """Print a friendly greeting for the given name."""
    print("Hello, " + name + ". Good morning!")

greet("Joseph")

The line def greet(name): defines the function. The line greet("Joseph") calls it. The value "Joseph" is passed into the function, and inside the function that value is available through the parameter named name. If a function expects one argument, it must be called with one argument unless a default value is provided.

A function definition cannot be empty. If you need to create a placeholder function before you know its body, use the pass statement. pass tells Python that the empty block is intentional.

3. Parameters, Arguments, Defaults, and Flexible Inputs

A parameter is the name written in the function definition. An argument is the actual value supplied when the function is called. In def greet(name):, name is a parameter. In greet("Joseph"), "Joseph" is an argument. Beginners often use these words interchangeably, but the distinction helps when reading error messages.

Default parameter values make an argument optional. If the caller does not provide that argument, Python uses the default. Keyword arguments let the caller name the argument being supplied, which can make calls easier to read and lets arguments appear in a different order.

Default and keyword arguments
def student(firstname, lastname="King", colour="red"):
    print(firstname, lastname, "favourite colour is", colour)

student(firstname="James")
student(firstname="James", colour="White")
student(firstname="Ada", lastname="Lovelace", colour="Blue")

Sometimes a function needs to accept an unknown number of arguments. A parameter beginning with *, often written as *args, collects extra positional arguments into a tuple. A parameter beginning with **, often written as **kwargs, collects extra keyword arguments into a dictionary.

Required parameters are still required

Default values only make the parameters with defaults optional. If a function has def student(firstname, lastname="King"):, the caller still has to provide firstname. Calling the function with only lastname="Gates" would raise an error because the required first name was never supplied.

*args and **kwargs
def show_colours(*colours):
    print("Second colour:", colours[1])

def show_named_colours(**colours):
    print("Third colour:", colours["third_colour"])

show_colours("Red", "Yellow", "Blue")
show_named_colours(first_colour="Red", second_colour="Yellow", third_colour="Blue")

Positional argument student("Ada", "Lovelace") The order of values clearly matches the parameter order.
Keyword argument student(firstname="Ada") You want the call to be easier to read or you want to skip over a defaulted argument.
Default parameter lastname="King" The function should have a normal value to use when the caller leaves that argument out.
*args def total(*numbers): The function may receive any number of positional values. Python stores them in a tuple.
**kwargs def profile(**details): The function may receive any number of named values. Python stores them in a dictionary.

4. Scope and Lifetime of Variables

Scope describes where a variable is recognized. A variable created inside a function is local to that function. It exists while the function is running and is separate from variables outside the function, even if the names match. This protects functions from accidentally changing unrelated values.

Local and outer variables
def my_func():
    x = 100
    print("Value inside function:", x)

x = 200
my_func()
print("Value outside function:", x)

The two variables named x are not the same variable. The local x belongs to the function call. The outer x belongs to the surrounding program. This idea becomes especially important when you write functions that calculate and return values. Instead of relying on a function to mysteriously change outside data, design it to receive inputs and return a result.

5. Docstrings and Return Values

A docstring documents what a function does. It appears as the first statement inside the function body, usually inside triple quotes. Good docstrings are short, direct, and useful to someone who wants to call the function without reading every internal line.

A function can display information with print(), but printing is not the same as returning. print() sends text to the console. return sends a value back to the place where the function was called. Returned values can be stored in variables, used in calculations, passed to other functions, or printed later.

Returning a value
def add_numbers(x, y):
    """Return the sum of two values."""
    total = x + y
    return total

num1 = 5
num2 = 6
answer = add_numbers(num1, num2)
print("The sum is", answer)

7. Recursion

Recursion happens when a function calls itself directly or indirectly. It can be useful when a problem can be described in terms of a smaller version of the same problem. For example, counting down from 5 can be described as printing 5 and then counting down from 4. Factorial can be described as multiplying a number by the factorial of the number before it.

Every recursive function needs a base case. The base case is the condition that stops the recursion. If a recursive function never reaches a base case, it keeps calling itself until Python raises a RecursionError. Python has a recursion limit to prevent a program from consuming memory forever.

Countdown recursion
def countdown(num):
    print(num)
    if num == 0:
        return
    countdown(num - 1)

countdown(5)

Factorial is another classic recursion example. The factorial of 4 means 4 * 3 * 2 * 1. A recursive version says: the factorial of n is n times the factorial of n - 1, until the base case is reached. Python's math module also provides math.factorial(), so the recursive version is mainly used here to understand the pattern.

Recursive factorial pattern
def recursive_factorial(n):
    if n == 1:
        return 1
    return n * recursive_factorial(n - 1)

print(recursive_factorial(4))

Recursion can make some problems elegant, but it is not always the best beginner tool. Recursive calls use memory, can be harder to debug, and require careful reasoning. If a loop is simpler and easier to read, a loop may be the better choice.

Recursion reference

Concept Meaning Why it matters
Base case The condition that stops the function from calling itself again. Without it, the function eventually raises RecursionError.
Recursive case The part of the function that calls itself with a smaller or simpler input. Each call should move closer to the base case.
Separate calls Each recursive call has its own local variables. Variables from one call do not automatically overwrite another call's local variables.
Recursion limit sys.getrecursionlimit() reports the limit; sys.setrecursionlimit(n) changes it. Changing the limit is rarely needed for beginner programs; a missing base case is usually the real bug.
Factorial shortcut math.factorial(n) Python's standard library already provides a tested factorial function.

8. Anonymous Lambda Functions

A lambda function is a small anonymous function created with the lambda keyword. Anonymous means the function does not need a regular name created with def. Lambda functions are useful when you need a short function for a short period of time, especially with tools like filter() and map().

A lambda can have any number of arguments, but only one expression. The expression is evaluated and returned automatically. If the logic needs several statements, a regular def function is clearer.

Lambda basics
def triple_function(x):
    return x * 3

triple_value = lambda x: x * 3

print(triple_function(5))
print(triple_value(5))
Lambda with if-else
min_value = lambda a, b: a if a < b else b
print(min_value(1, 2))

Lambda reference

Rule Example Beginner interpretation
Basic syntax lambda x: x * 3 Take x, evaluate x * 3, and return the result automatically.
Multiple inputs lambda x, y: x * y A lambda can accept more than one argument.
One expression lambda a, b: a if a < b else b Conditional expressions are allowed, but full multi-line logic belongs in def.
Best use filter(lambda n: n % 2 == 0, numbers) Use lambdas for short functions passed into another function.

9. filter(), map(), and Lambda

The filter() function keeps items from an iterable when a function returns True for those items. The map() function transforms each item in an iterable by applying a function to it. Both return iterator objects, so beginners often wrap them in list() to view the result.

The difference is important. Filtering chooses which items stay. Mapping changes each item into a new value. If you are selecting only even numbers, think filter(). If you are doubling every number, think map().

filter and map
list_one = [1, 7, 100, 8, 9, 17, 25, 16, 35, 80, 5, 4]

is_even_flags = list(map(lambda x: x % 2 == 0, list_one))
even_numbers = list(filter(lambda x: x % 2 == 0, list_one))
doubled_numbers = list(map(lambda x: x * 2, list_one))

print(is_even_flags)
print(even_numbers)
print(doubled_numbers)

You can also combine filter() with membership tests. To find the intersection of two lists, filter the second list by keeping only values that also appear in the first list. Later lessons may show other ways to solve this, but this example reinforces how functions can be passed into functions.

filter(), map(), and membership reference

Tool Pattern Result idea
filter() list(filter(lambda x: x % 2 == 0, numbers)) Keep only the values where the function returns True.
map() list(map(lambda x: x * 2, numbers)) Build a new value for every item in the original iterable.
Boolean map list(map(lambda x: x % 2 == 0, numbers)) Return True or False for each original item.
Intersection list(filter(lambda x: x in first_list, second_list)) Keep items from the second list only when they also appear in the first list.

1. Files and the File Workflow

A file is a named location on disk used to store related information. Variables and lists are useful while a program is running, but they normally disappear when the program exits. Files solve that problem by saving data in non-volatile storage, such as a hard drive or solid-state drive. A coffee inventory program, for example, needs its records to still exist tomorrow. A file gives the program a place to keep them.

File input/output, often shortened to file I/O, follows a simple pattern: open the file, perform an operation, and close the file. The operation might be reading existing data, writing new data, appending more data to the end, or copying content into another file. Closing is important because it releases the operating-system resources connected to that file and helps ensure pending writes are completed.

Beginner mental model

Opening a file is like checking out a notebook from storage. Reading or writing is the work you do with the notebook. Closing returns it safely so the system knows you are finished.

2. Opening and Closing Files

Python opens files with the built-in open() function. The function returns a file object, sometimes called a handle, that lets the program read from or write to the file. The file mode tells Python what kind of access you want. Mode r reads, w writes and truncates existing content, a appends to the end, x creates a new file only if it does not already exist, b means binary mode, and + allows updating.

File mode reference

Mode Name What it does
r Read Opens an existing file for reading. This is the default mode. It raises an error if the file does not exist.
w Write Creates a file if needed and erases existing content. Use carefully because old data is replaced.
x Exclusive creation Creates a new file and raises an error if a file with that name already exists.
a Append Creates a file if needed and writes new content at the end without erasing existing content.
t Text Reads and writes strings. This is the default companion mode for normal text files.
b Binary Reads and writes bytes, which is used for non-text data such as images or compiled files.
+ Update Adds both reading and writing ability, such as r+ or w+.
Opening files
read_file = open("cars.txt", "r", encoding="utf-8")
write_file = open("notes.txt", "w", encoding="utf-8")
append_file = open("inventory.txt", "a", encoding="utf-8")

read_file.close()
write_file.close()
append_file.close()

The safer modern pattern is the with statement. A with block automatically closes the file when the block ends, even if an error occurs inside the block. For beginner file work, prefer with open(...) unless an assignment specifically asks for manual closing.

3. Writing and Reading Data

To write to a file, open it in write, append, or exclusive-creation mode. Write mode w creates the file if needed but erases existing content if the file already exists. Append mode a keeps existing content and adds new content to the end. That difference matters in inventory-style assignments, where new records should not erase old records.

Writing lines
with open("myfile.txt", "w", encoding="utf-8") as my_file:
    my_file.write("Willis College Header\n")
    my_file.write("Willis College body 1\n")
    my_file.write("Willis College body 2\n")

Reading can happen in several ways. read() returns the file content as a string. If you pass a size, it reads up to that many characters. readline() reads one line. readlines() returns a list of lines. A for loop can also read a file line by line, which is often the cleanest pattern for large files.

Reading line by line
cars = []

with open("cars.txt", "r", encoding="utf-8") as file:
    for line in file:
        cars.append(line.strip())

print(cars)

4. File Methods and OS Module Methods

File objects include methods for reading, writing, positioning, and checking file capabilities. tell() returns the current file position. seek() changes the file position. writable() and readable() report whether the file object supports writing or reading. write() writes one string, while writelines() writes multiple strings.

The os module lets Python interact with the operating system. It can get the current working directory, change directories, create directories, list files, remove files, rename files, and check whether a path exists. File deletion should be handled carefully: os.remove() deletes a file, and os.rmdir() removes an empty directory.

5. Modules

A module is a Python file that contains related code. If you create a file named calculator.py, then calculator is the module name. A module can contain functions, variables, classes, and other statements. Modules help keep programs organized because related behavior can live in its own file instead of being mixed into one large script.

A calculator module might hold functions such as add(), subtract(), multiply(), and divide(). A separate main.py file can import that module and use its functions. This separates reusable logic from the script that runs the program.

calculator.py
def add(num_one, num_two):
    """Return the sum of two numbers."""
    return num_one + num_two

def subtract(num_one, num_two):
    """Return num_one minus num_two."""
    return num_one - num_two

def multiply(num_one, num_two):
    """Return the product of two numbers."""
    return num_one * num_two

def divide(num_one, num_two):
    """Return num_one divided by num_two."""
    return num_one / num_two
main.py
import calculator as cal

print(cal.add(1, 5))
print(cal.subtract(6, 9))
print(cal.multiply(1, 5))
print(cal.divide(10, 2))

A module can be imported by another file, or it can be run directly as a script. Python sets the special variable __name__ to "__main__" only for the file being run directly. That is why many examples use an if __name__ == "__main__": guard. It lets a file provide reusable functions when imported, while still having a starting point when run as the main program.

Main guard pattern
import calculator as cal

def main():
    print(cal.add(1, 5))
    print(cal.divide(10, 2))

if __name__ == "__main__":
    main()

PEP 8 recommends short lowercase module names. Imports should appear near the top of the file, after any module comment or docstring. Put imports on separate lines and group standard-library imports, third-party imports, and application-specific imports with blank lines between groups.

Module coding standard reference

Practice Reason
Use short lowercase module names A file such as calculator.py is easy to import and easy to read.
Place imports near the top Readers can immediately see what outside code the file depends on.
Use separate import lines import os and import sys on separate lines are easier to scan and edit.
Group imports Put standard-library imports first, then third-party imports, then your own project imports.
Keep reusable logic out of main.py A module is easiest to reuse when function definitions are separate from one-time program flow.

6. Import Styles and Module Namespaces

The simplest import style is import calculator. With that style, you access a function using the module name and dot operator, such as calculator.add(1, 2). You can also give the module an alias with import calculator as cal, then call cal.add(1, 2).

Python can import specific objects into the current namespace with from calculator import add. After that import, you can call add(1, 2) without writing the module name. Python also allows from calculator import *, but importing everything is usually discouraged because it becomes harder to see where names came from and easier to accidentally overwrite a name.

Import styles
import calculator
import calculator as cal
from calculator import add

print(calculator.add(1, 2))
print(cal.add(1, 2))
print(add(1, 2))

A module is initialized the first time it is imported during a Python session. If the same module is imported again, Python usually reuses the already-loaded module. That makes imports efficient, but it also means changes during an interactive session may require restarting the session or reloading the module.

Import style reference

Style Example When it helps
Import module import calculator Keeps names clear because calls include the module name, such as calculator.add().
Import with alias import calculator as cal Shortens a long module name while preserving the module namespace.
Import one object from calculator import add Useful when one function or constant is used often and the source is still obvious.
Import all from calculator import * Allowed by Python, but avoid it in normal beginner code because it hides where names came from.

As a project grows, one folder full of modules can become hard to manage. A package is a directory that groups related modules. 1. Data Manipulation and Parsing

Data manipulation means taking raw information and reshaping it into a form that is easier to understand, analyze, or use in another program. A raw dataset might contain thousands of rows, inconsistent dates, empty cells, duplicate records, columns you do not need, and values that are technically present but clearly wrong. Manipulation is the process of organizing that data: selecting useful parts, correcting mistakes, filling or removing missing values, grouping related rows, and producing summaries.

Parsing is closely related. When Python parses data, it reads information from a source and interprets its structure. A CSV file uses commas to separate fields. A JSON file stores nested key-value data. A text file may use spaces or tabs. Pandas helps Python parse these formats into data structures you can inspect and manipulate.

For a beginner, the important mindset shift is that Pandas is not just another way to store values. It is a workflow library. You load data, inspect it, clean it, analyze it, and sometimes export or save the result. Lesson 5 moves through that whole path.

Beginner mental model

Think of a Pandas dataset as a table with labels. The labels help you ask questions like "show me this column," "show me these rows," "summarize this group," or "replace missing values in this field."

2. Installing and Importing Pandas

Pandas is not part of Python's standard library. That means a normal Python installation may not include it until you install the package. In PyCharm, you can install it from the Python Packages window by searching for pandas and choosing Install. In a terminal, the usual command is pip install pandas. Many data examples also use NumPy and Matplotlib, so you may eventually install those too with pip install numpy matplotlib.

Once Pandas is installed, your script still has to import it. The common import style is import pandas as pd. The as pd part creates a short alias. Instead of typing pandas.Series(...) or pandas.DataFrame(...), you can type pd.Series(...) and pd.DataFrame(...). The alias does not change the library; it only gives your program a shorter local name for it.

3. Pandas Series

A Series is one of the two primary Pandas data structures. It is one-dimensional, which means it behaves like a single labeled column of data. A Series can store many Python-style data types, including integers, floats, strings, and Boolean values. The labels attached to the values are called the index.

If you create a Series from a list and do not provide labels, Pandas creates a default integer index that starts at 0. This should feel familiar from list indexing. If you provide your own labels with the index= argument, you can access values by those labels instead. If you create a Series from a dictionary, the dictionary keys become the labels automatically.

4. Pandas DataFrames

A DataFrame is the second primary Pandas data structure. It is two-dimensional, with labeled rows and labeled columns. If a Series is like one labeled column, a DataFrame is like a complete table. This makes DataFrames feel similar to spreadsheets, but they are controlled by Python code and can handle repeatable data workflows much more reliably than manual clicking.

DataFrames have a row index and column labels. The row index identifies rows. The column labels identify fields such as Name, Age, Salary, or Engine Information.EngineType. Columns can contain different data types, so one column might store strings while another stores integers or floats.

print(people)

5. Reading CSV, Text, and JSON Files

Real datasets usually come from files. Pandas includes reader functions that parse common file formats into DataFrames. A CSV file is a comma-separated values file. It is plain text, widely supported, and common in spreadsheets and exported reports. Pandas reads CSV files with pd.read_csv().

Read a CSV file
import pandas as pd

cars = pd.read_csv("cars.csv")

print(cars.to_string())
print(cars)

The difference between print(cars) and print(cars.to_string()) matters with large datasets. Pandas may shorten the normal printed display by showing the first rows and last rows. Calling to_string() asks Pandas to produce a full string representation of the DataFrame.

Columns can be selected with square brackets. If you pass a list of column names, Pandas returns a DataFrame containing those columns. The column name has to match the real file header exactly, including spaces and punctuation. In the lesson examples, names such as Engine Information.EngineType require careful spelling.

Select a column
import pandas as pd

cars = pd.read_csv("cars.csv")

print(cars[["Engine Information.EngineType"]])

Pandas uses loc to select rows by label. The basic idea is dataframe.loc[list_of_indexes]. If your DataFrame uses default row labels, those labels look like row numbers starting at 0. If your DataFrame has custom labels, loc uses those labels instead.

import pandas as pd

cars = pd.read_csv("cars.csv")

print(cars.loc[[0, 1, 2]])

import pandas as pd

print(students)

students_named = pd.read_csv(
    "students.txt",
    sep=" ",

)
print(students_named)

7. Cleaning Empty Cells, Wrong Formats, Wrong Data, and Duplicates

Data cleaning is the process of making a dataset trustworthy enough for analysis. The chapter focuses on four common problems: empty cells, wrong formats, wrong data, and duplicate records. These problems matter because analysis methods do exactly what the data tells them to do. If the dataset contains blanks, impossible values, or repeated records, your summary can be misleading.

Empty cells can be removed with dropna() or replaced with fillna(). By default, many Pandas cleaning methods return a new DataFrame and leave the original unchanged. If you want to change the original object directly, some methods accept inplace=True. Beginners should be deliberate here: assigning the result to a new variable is often clearer because you can compare before and after.

Handle missing values
import pandas as pd

df_cars = pd.read_csv("cars.csv")

cleaned = df_cars.dropna()
df_cars["Dimensions.Length"].fillna(10, inplace=True)

Wrong format means a value exists but is stored in a form that makes analysis difficult. Dates are a common example. A date column may contain strings that should be converted to date-time values. Pandas provides pd.to_datetime() for this. After conversion, rows that still cannot be converted can be removed with dropna(subset=[...]).

Convert date formats
import pandas as pd

df = pd.read_csv("cars.csv")

df["Date"] = pd.to_datetime(df["Date"], errors="coerce")
df.dropna(subset=["Date"], inplace=True)

Wrong data means the value is in the right general format but is not believable or valid. A speed of 1000 km/h in a normal car dataset is probably not a formatting issue; it is a bad value. In a small dataset, you might replace one value with df.loc[row_index, "ColumnName"] = new_value. In a larger dataset, you might loop over indexes and replace or drop rows that fall outside a boundary.

Replace or remove wrong data
import pandas as pd

df = pd.read_csv("cars.csv")

for row_index in df.index:
    if df.loc[row_index, "Speed"] > 150:
        df.loc[row_index, "Speed"] = 150

for row_index in df.index:
    if df.loc[row_index, "Speed"] < 0:
        df.drop(row_index, inplace=True)

Duplicate records can be detected with duplicated(). It returns Boolean values for rows: True for a duplicate and False otherwise. To remove duplicates, use drop_duplicates(). With inplace=True, the original DataFrame is modified.

Find and remove duplicates
import pandas as pd

df = pd.read_csv("cars.csv")

print(df.duplicated())
df.drop_duplicates(inplace=True)

After data is loaded and cleaned, you often reshape it or summarize it. Dropping unnecessary columns keeps the dataset focused. Inserting a calculated or generated column adds information. Selecting by data type lets you work only with numeric columns when preparing for analysis or plotting.

Drop, inspect, select, and insert

describe() is useful for quick numeric summaries, but grouped summaries are where Pandas becomes especially powerful. groupby() splits the data into groups based on a column, then an aggregation function such as count(), sum(), or mean() summarizes another column inside each group.

Group and aggregate
import pandas as pd

Correlation measures how strongly numeric columns move together. Pandas calculates correlations with corr(). The result ranges from -1 to 1. A value near 1 means two values tend to increase together. A value near -1 means one tends to increase while the other decreases. A value near 0 means there is little linear relationship. Pandas ignores non-numeric columns when computing correlation.

Calculate correlation
import pandas as pd

df = pd.read_csv("Census.txt")

print(relationship)

10. Python Pickle: Storing and Loading Objects

Pickle is a Python module for serialization and deserialization. Serialization means converting an object in memory into a byte stream that can be written to disk, sent over a network, or stored for later. Deserialization reverses the process and reconstructs the object from the byte stream.

Pickle can be useful when you want to save program state, cache Python objects, store objects in a database, or send Python data between Python programs. It is Python-specific, so it is not a good choice when another programming language needs to read the data. CSV and JSON are better cross-language formats.

Security warning

Never unpickle data from an untrusted or unauthenticated source. Pickle can execute instructions during loading, so malicious pickle files are dangerous.

Pickle module interface

Tool What it does
pickle.dump(obj, file)Serializes an object and writes it to an open binary file.
pickle.load(file)Reads a pickled object from an open binary file and reconstructs it.
pickle.dumps(obj)Serializes an object and returns bytes instead of writing a file.
pickle.loads(bytes)Reconstructs an object from a bytes object.
pickle.HIGHEST_PROTOCOLThe highest protocol version available in the current Python version.
pickle.DEFAULT_PROTOCOLThe protocol Python uses when you do not choose one.

Protocol and compatibility arguments

The full Pickle functions include optional arguments for protocol and compatibility. In beginner code, you will most often rely on the defaults, but the names are worth recognizing when you see them in documentation.

Argument Where it appears Meaning
protocol dump() and dumps() Chooses the Pickle protocol version. If omitted, Python uses the default protocol. A negative value selects the highest available protocol.
fix_imports dump() and load() Helps map old Python 2 module names to Python 3 names for compatibility with older pickle streams.
encoding and errors load() and loads() Control how Python 2 string data is decoded when older pickle data is loaded in Python 3.

Pickle files are opened in binary mode. Use "wb" when writing a pickle file and "rb" when reading one. The w and r mean write and read; the b means binary.

Write and read a pickle file
import pickle
import numpy as np

my_data_dict = {
    "location_one": np.random.random(20),
    "location_two": np.random.random(20)
}

with open("pickle.pkl", "wb") as pickle_file:
    pickle.dump(my_data_dict, pickle_file)

with open("pickle.pkl", "rb") as pickle_file:
    my_data = pickle.load(pickle_file)

print(my_data)

Picklable object types

Pickle can handle many ordinary Python objects, including Booleans, integers, floats, complex numbers, strings, tuples, lists, sets, and dictionaries that contain picklable objects. Classes and functions can also be pickled when they are defined at the top level of a module.

Pickle is also sensitive to Python context. If a pickle file was created with a different Python version or with custom classes that no longer exist in the same module location, loading may fail. This is another reason to use Pickle for trusted Python-to-Python workflows, not for long-term public data exchange.

Pickle exceptions

Exception Meaning
pickle.PickleErrorBase class for Pickle-related exceptions.
pickle.PicklingErrorRaised when an object cannot be pickled.
pickle.UnpicklingErrorRaised when loading fails because data is corrupted, invalid, or unsafe.

To explore Pickle further in a Python console, import the module and run help(pickle). This follows the same habit from earlier lessons: when a module or keyword is unfamiliar, use Python's built-in help system to inspect it.
