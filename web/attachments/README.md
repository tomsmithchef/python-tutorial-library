# Assignment Attachments

Place downloadable starter files, datasets, lab handouts, or other assignment resources in this folder.

After adding a file, register it in `../assignment-attachments.js` so the testing environment can display a download button.

Suggested layout:

```text
attachments/
  lesson1/
    starter-file.py
  lesson2/
    lab-data.csv
```

Keep completed solutions out of this folder.
