Instructions

Complete the following steps:

Open PyCharm IDE.
Create a new Python file and name it RPSGame.py.
Write a Python script that will determine the result of a rock, paper, scissors game, given Player 1 and Player 2’s choices. The program should print out the result based on the rules below.
Run your code and ensure your script prints the right message based on the rules provided.
Save your file.
Note: The script should accept only these input from two players: “Rock”, “Paper” and “Scissors”.

Rules:

 
|                     | Player 2 - Rock  | Player 2 - Paper | Player 2 - Scissors |
 
| Player 1 - Rock     |        Draw      | Player 2 wins    | Player 1 wins       |

| Player 1 - Paper    |  Player 1 wins   |      Draw        | Player 2 wins       |

| Player 1 - Scissors |  Player 2 wins   | Player 1 wins    | Draw                |
